# Git Rules

Keep commits focused.

Before commit:
- inspect `git status`;
- inspect `git diff`;
- run relevant checks;
- verify no secrets are included.

Do not rewrite history unless explicitly asked.
Do not mix unrelated refactors with feature work.

Preferred commit style:
`feat: ...`
`fix: ...`
`test: ...`
`refactor: ...`
`docs: ...`
`chore: ...`
